# SIFT своими руками — практикум

Самостоятельный учебный подпроект к конспекту [SIFT (Lowe, 2004)](../../rus/SIFT_конспект.md).

## Цель

Пройти весь конвейер SIFT руками — масштабное пространство → детектор → ориентация → дескриптор →
сопоставление → RANSAC — на `numpy` и базовых примитивах OpenCV (`GaussianBlur`, `resize`), на каждом шаге
сверяясь с эталоном `cv2.SIFT_create` / `BFMatcher` / `FlannBasedMatcher` / `findHomography`, и
количественно оценить результат на парах изображений с известной гомографией.

Реализация повторяет OpenCV в деталях, поэтому совпадение получается практически точным:
те же ключевые точки (100% в пределах 2 px, медианное расхождение 0), дескрипторы на точках OpenCV —
косинусная близость ≥ 0.99997, в шкале OpenCV (`uchar`) все компоненты совпадают с точностью ±1.

## Структура

```
sift_lab/
├── sift_методичка.ipynb   # методичка: теория (рус.) + код + сравнения с OpenCV, с сохранёнными результатами
├── siftlab/               # тот же код в виде пакета (докстринги на русском)
│   ├── pyramid.py         #   разд. 3, 3.2–3.3: удвоение, гауссова пирамида, DoG
│   ├── detector.py        #   разд. 3.1, 4, 4.1: 26 соседей, уточнение по Тейлору, контраст, края
│   ├── orientation.py     #   разд. 5: 36-бинная гистограмма ориентаций
│   ├── descriptor.py      #   разд. 6.1: 4×4×8, трилинейная интерполяция, обрезка 0.2, RootSIFT
│   ├── matching.py        #   разд. 7.1: перебор L2, ratio test, cross-check
│   ├── geometry.py        #   нормализованный DLT, RANSAC для гомографии
│   ├── evaluation.py      #   синтез пар с известной H, повторяемость, точность
│   ├── pipeline.py        #   sift_detect_and_compute, конвертация в/из cv2.KeyPoint
│   └── data.py            #   загрузка примеров OpenCV в data/ (кэш) или синтетика без сети
├── tests/test_siftlab.py  # быстрые проверки (~1 с)
├── tools/build_notebook.py# сборщик ноутбука: вставляет функции из siftlab/ в ячейки дословно
├── data/                  # кэш изображений (создаётся автоматически, в .gitignore)
└── requirements.txt
```

## Установка

Нужен Python ≥ 3.10 (проверено на 3.14). Всё ставится в локальное окружение `.venv` внутри папки:

```bash
cd практика/sift_lab
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
# или без фиксированных версий:
# .venv/bin/pip install numpy opencv-python matplotlib jupyter nbconvert ipykernel pytest
```

## Запуск

```bash
.venv/bin/jupyter lab sift_методичка.ipynb        # или: .venv/bin/jupyter notebook
```

Ноутбук сохранён с результатами — графики и числа видны сразу. Полный перезапуск (`Run All`) занимает
~30 с на CPU. Без интерфейса:

```bash
.venv/bin/jupyter nbconvert --to notebook --execute --inplace sift_методичка.ipynb --ExecutePreprocessor.timeout=600
```

Тесты:

```bash
.venv/bin/python -m pytest -q tests        # или без pytest: .venv/bin/python -m tests.test_siftlab
```

При первом запуске примеры `box.png`, `box_in_scene.png`, `graf1.png`, `graf3.png` скачиваются из
`https://raw.githubusercontent.com/opencv/opencv/4.x/samples/data/` в `data/`. Без сети подставляется
синтетическая текстура — ноутбук всё равно выполнится (но пара «box → сцена» станет бессмысленной).

## Порядок работы

1. Прочитайте в [конспекте](../../rus/SIFT_конспект.md) разделы 3–7 (хотя бы бегло) и «Сводку гиперпараметров».
2. Идите по ноутбуку сверху вниз: каждый раздел — короткая теория с формулами, код функции, демонстрация и
   сравнение с OpenCV.
   * 0 — данные и синтетическая пара с известной гомографией;
   * 1 — эталонный SIFT OpenCV, параметры, расшифровка `KeyPoint.octave`;
   * 2 — пирамида и DoG (разд. 3);
   * 3 — детектор (разд. 3.1, 4, 4.1), сравнение точек с OpenCV;
   * 4 — ориентация (разд. 5);
   * 5 — дескриптор (разд. 6.1), **ключевой тест**: свой дескриптор на точках OpenCV + типичные ошибки соглашений;
   * 6 — сопоставление (разд. 7.1–7.2): аналог рис. 11, cross-check, BF vs FLANN;
   * 7 — RANSAC + DLT, наложение, реальные пары;
   * 8 — повторяемость, precision/recall, устойчивость к повороту и масштабу: свой SIFT vs OpenCV SIFT vs ORB;
   * 9 — упражнения с подсказками.
3. Выполните упражнения раздела 9 — меняйте функции прямо в ячейках.

Если меняете код в `siftlab/`, пересоберите ноутбук, чтобы ячейки остались синхронны с пакетом:

```bash
.venv/bin/python tools/build_notebook.py && .venv/bin/jupyter nbconvert --to notebook --execute --inplace sift_методичка.ipynb
```

(Сборщик перезаписывает ноутбук целиком — правки, сделанные прямо в ячейках, при этом пропадут.)
Последняя ячейка ноутбука проверяет, что код ноутбука и пакета даёт одинаковый результат.
